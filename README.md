# Invitación de Laura y Jorge

Invitación web personalizada para **Francesco Monachello y Sra.**, con **2 cupos**.

## Publicar en GitHub Pages

1. Cree un repositorio nuevo en GitHub.
2. Suba todos los archivos de esta carpeta a la rama `main`.
3. Abra `Settings` → `Pages`.
4. En `Source`, seleccione `GitHub Actions`.
5. Espere a que termine la acción **Publicar invitación en GitHub Pages**.

La página funciona sin base de datos y sin servidor propio.
